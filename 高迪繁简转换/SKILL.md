# 高迪繁简转换

将 Word (.docx) 文档中的简体中文转换为繁体中文，使用词组级语义判断。
也支持对已有繁体文档进行一对多语义检查和修正。

## 为什么不用简单字符映射

简→繁不是一对一映射，许多简体字对应多个繁体字，需根据上下文判断：

| 简体 | 繁体1 | 繁体2 | 示例 |
|------|-------|-------|------|
| 里 | 里(里程) | 裏(里面) | 万里 vs 裏面 |
| 发 | 發(发展) | 髮(头发) | 發表 vs 頭髮 |
| 干 | 幹(干部) | 乾(干燥) | 幹部 vs 乾淨 |
| 面 | 面(面孔) | 麵(面条) | 面容 vs 麵條 |
| 只 | 只(只是) | 隻(一只) | 只要 vs 一隻 |
| 后 | 后(皇后) | 後(背后) | 皇后 vs 背後 |
| 历 | 歷(历史) | 曆(日历) | 歷史 vs 日曆 |
| 钟 | 鐘(钟表) | 鍾(钟情) | 黃鐘 vs 鍾情 |
| 系 | 系(系统) | 繫(联系) | 系統 vs 聯繫 |
| 复 | 復(回复) | 複(复杂) | 回覆 vs 複雜 |
| 脏 | 臟(心脏) | 骯(脏话) | 心臟 vs 髒話 |
| 志 | 志(志向) | 誌(杂志) | 志向 vs 雜誌 |
| 尽 | 盡(尽头) | 儘(尽快) | 盡頭 vs 儘快 |
| 征 | 征(出征) | 徵(征兆) | 出征 vs 徵兆 |

## 技术方案

使用 opencc 库的 `s2t` 模式，保留古典字形（裏、喫、穀等），适合书法和古籍排版。

### 自动检测模式（默认）

脚本自动检测原文是简体还是繁体：

- **简体原文** → 完整 s2t 转换（所有字符）
- **繁体原文** → 仅修正一对多语义映射错误（不改变字形变体）

字形变体（如 群/羣、峰/峯、绛/絳）在繁体中均可接受，不做修改。

字形特点：
- 裏（非裡）— 古典字形，书法常用
- 喫（非吃）— 古文用法
- 穀（五穀）— 古典写法
- 正确处理一对多语义映射（发→發/髮、干→幹/乾、面→面/麵 等）

## 使用方法

1. 确认用户要处理的 .docx 文件路径
2. 运行脚本：
   ```bash
   python <skill-dir>/scripts/s2twp.py <输入文件> [输出文件] [--skip N] [--mode auto|full|semantic]
   ```
3. 默认输出：同名_繁体.docx（如指定输出文件则覆盖源文件也不新建）

### 参数

| 参数 | 说明 |
|------|------|
| 输入文件 | 必填，.docx 文件路径 |
| 输出文件 | 可选，默认同名_繁体.docx。可指定与输入相同以覆盖 |
| --skip N | 跳过前 N 个段落不转换（如目录区域） |
| --mode | 转换模式：auto（默认，自动检测）、full（完整转换）、semantic（仅一对多） |

### 模式说明

| 模式 | 行为 |
|------|------|
| auto | 自动检测：简体→完整转换，繁体→仅修正一对多 |
| full | 完整 s2t 转换（含字形变体），适合简体原文 |
| semantic | 仅修正一对多语义映射，适合检查繁体文档 |

### 可选：指定转换范围

用户可能只需要转换正文部分，保留目录/标题为简体。此时用 `--skip` 参数跳过前面的段落。

### 繁体文档检查

当用户提供已标注为繁体的文档时，脚本自动切换为"仅修正一对多"模式，
只修复语义映射错误（如"里面"应为"裏面"），不改字形变体。

## 依赖

- Python 3 + python-docx + opencc (pip install opencc)

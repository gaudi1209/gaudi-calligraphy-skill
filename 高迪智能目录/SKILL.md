# 高迪智能目录

将 Word 文档中的手动目录（篇名---页码格式）转换为 Word 原生智能目录。

## 效果

- 目录条目带超链接，点击可跳转到对应章节
- 调整排版后，右键目录 → 更新域（或 Ctrl+A 后 F9）即可自动刷新页码
- 使用 Word 的 TC + TOC 域机制，兼容 WPS 和 Microsoft Word

## 使用方法

1. 确认用户要处理的 .docx 文件路径
2. 运行脚本：

```bash
python <skill-dir>/scripts/smart_toc.py "<输入文件>" ["<输出文件>"] [--toc-start N] [--toc-end N] [--heading N]
```

### 参数说明

| 参数 | 说明 |
|------|------|
| 输入文件 | 必填，.docx 文件路径 |
| 输出文件 | 可选，默认原名_智能目录.docx |
| --toc-start | 目录起始段落索引（0-based），默认自动检测 |
| --toc-end | 目录结束段落索引（0-based），默认自动检测 |
| --heading | 正文章节标题起始段落索引（0-based），默认自动检测 |

### 自动检测逻辑

脚本会自动检测：
1. **目录区域**：连续包含 `---` 虚线的段落
2. **正文起始**：目录之后第一个含"篇"字的短标题
3. **章节匹配**：精确匹配 + 模糊匹配（处理目录与正文标题略有差异的情况）

如果自动检测不准确，用户可通过参数手动指定。

## 目录格式要求

输入文档的目录条目应为以下格式：

```
篇名或章节名----------页码
```

中间有连续虚线（至少3个），虚线前是章节名，虚线后是页码。

## 依赖

- Python 3 + python-docx + pywin32
- 系统需安装 WPS Office 或 Microsoft Word

## 注意事项

- 脚本会启动 Word/WPS 后台进程，耗时较长（约30秒）
- 处理后原文档不会被修改，输出为新文件
- 如果 WPS COM 对象在 Close 后失效（`<unknown>.Open` 错误），需要重新运行

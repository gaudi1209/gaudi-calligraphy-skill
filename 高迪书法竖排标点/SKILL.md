# 高迪书法竖排标点

将 Word (.docx) 文档中所有标点符号修改为竖排书法格式：替换字形 + 统一格式。

## 默认格式

| 属性 | 值 |
|------|-----|
| 颜色 | 深红 `#8B0000` |
| 字体 | 楷体 |
| 字号 | 小四 (12pt) |

## 字形替换规则

### 引号 → 角括号

| 原字符 | 替换为 | 位置 |
|--------|--------|------|
| " (U+201C，左双引号) | 『 (U+300E) | 上标 |
| " (U+201D，右双引号) | 』 (U+300F) | 下标 |
| ' (U+2018，左单引号) | 「 (U+300C) | 上标 |
| ' (U+2019，右单引号) | 」 (U+300D) | 下标 |
| " (全角左双引号) | 『 | 上标 |
| " (全角右双引号) | 』 | 下标 |
| ' (全角左单引号) | 「 | 上标 |
| ' (全角右单引号) | 」 | 下标 |

### 书名号 → 波浪下划线

| 原字符 | 处理方式 | 说明 |
|--------|----------|------|
| 《》 | 删除标记，对书名文字添加波浪下划线 | 符合 GB/T 15834-2011 浪线式书名号 |
| 〈〉 | 删除标记，对书名文字添加波浪下划线 | 同上 |

**实现方式（跨 run 处理）：**
1. 先用 `handle_book_name_markers(para)` 逐段落处理，在 `process_run` 之前调用
2. 删除 `《` `》` `〈` `〉` 字符
3. 对书名文字的 run 添加 `w:u w:val="wave" w:color="8B0000"`（深红波浪下划线）
4. 在竖排模式（`textDirection=tbRl`）下，波浪下划线**自动显示在文字左侧**

**关键：** 不能用 `﹏` (U+FE4F) 字符夹住书名（如 `﹏书名﹏`），这种方式在竖排中无法正确显示。必须用 Word 原生的波浪下划线格式。

**跨 run 处理流程：**
1. 遍历段落中所有 run
2. 含 `《》` 的 run 按 `《` / `》` 拆分为多个新 run（非标记文字 + 标记位置记录）
3. 跟踪 `in_book` 状态：遇到 `《` 设为 True，遇到 `》` 设为 False
4. 所有 `in_book=True` 期间的 run（包括不含标记的 run）均添加波浪下划线
5. 纯标记 run（只有 `《` 或 `》`）直接删除

### 括号 → 直式括号

| 原字符 | 替换为 | 位置 |
|--------|--------|------|
| （ | ︵ (U+FE35) | 不调整 |
| ） | ︶ (U+FE36) | 不调整 |
| ( | ︵ | 不调整 |
| ) | ︶ | 不调整 |

### 角括号（原样保留）

| 字符 | 位置 |
|------|------|
| 「 『 | 上标 |
| 」 』 | 下标 |

### 黑括号（保持正文字号）

| 字符 | Unicode | 处理方式 |
|------|---------|----------|
| 【 | U+3010 | 深红、楷体，**保持原字号**，不调上下标 |
| 】 | U+3011 | 同上 |
| ︻ | U+FE3B | 同上 |
| ︼ | U+FE3C | 同上 |

**说明：** 黑括号常用于章节标题标记（如 `︻ 莊子逍遙遊第一︼`），应与正文字号统一（如一号 26pt），不应缩小为小四(12pt)，也不应设为上标/下标。

### 其他标点

| 类型 | 位置 |
|------|------|
| ，。！？；：、…·～等 | 上标 |
| - – — (连字符/破折号) | 不调整 |

### 特殊符号

圈号数字 ①②③④⑤⑥⑦⑧⑨⑩ 等 (U+2460-U+24FF)：
- 小四(12pt)、深红、楷体
- **不调整上下标位置**

2. 运行脚本：
   ```bash

   ```

## 自定义格式

常用颜色：
- 深红: `#8B0000` | 红色: `#FF0000` | 暗红: `#800000` | 朱红: `#C0322D`

## 排版检查

### 防止正文孤行

章节标题不应单独出现在页面底部（标题在页底，正文在下一页）。使用 Word 段落属性 `keepWithNext` + `keepLines` 自动防止。

**正确方法：**
```python
from docx.oxml.ns import qn
from lxml import etree

for para in doc.paragraphs:
    if is_chapter_title(para):  # 判断是否为章节标题
        pPr = para._element.find(qn('w:pPr'))
        if pPr is None:
            pPr = etree.SubElement(para._element, qn('w:pPr'))
            para._element.insert(0, pPr)
        # 标题与下一段保持同页
        etree.SubElement(pPr, qn('w:keepNext'))
        # 标题内部不分页
        etree.SubElement(pPr, qn('w:keepLines'))
```

**⚠️ 不要用手动分页符（`w:br type="page"`）修复孤行！** 原因：
- 标题前出现整页空白
- 修复一处孤行会创建新的孤行（打地鼠效应，标题位置变化导致其他标题移位）
- 每次调整排版都需要重新检查和修复
- `keepWithNext` 是 Word 原生的段落实体属性，由 Word 引擎自动处理分页，排版调整后仍然有效

**验证方法：** 使用 Word COM 检查每个标题的下一段是否在同一页（比较标题和下一段的页码）。

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 引号未被替换 | 源码中 `"` 写成了 ASCII 直引号 (U+0022) 而非弯引号 (U+201C) | 确保 CHAR_REPLACE 用 Unicode 转义：`'\u201c'`、`'\u201d'` |
| EPUB 弯引号未处理 | build 脚本的替换映射不含弯引号 | 在构建阶段也要包含 `""→『』`、`''→「」` 的映射 |
| 书名号显示为﹏字符 | 旧版脚本用 `﹏` 替换 `《》` | 新版已修复：删除标记 + 添加波浪下划线。旧文档需重新处理 |
| 标题前出现整页空白 | 用手动分页符修复孤行导致 | 改用 `keepWithNext` + `keepLines` 段落属性 |

**关键提醒：** EPUB 提取的文本中引号是弯引号 `""`（U+201C/201D）和 `''`（U+2018/2019），不是 ASCII 直引号。Python 源码中直接写 `"` 会被当作直引号 (U+0022)，必须用 `\u201c`/`\u201d` 转义或从文件中复制正确的弯引号字符。

# 高迪书法竖排标点

将 Word (.docx) 文档中所有标点符号修改为竖排书法格式：替换字形 + 统一格式。

## 默认格式

| 属性 | 值 |
|------|-----|
| 颜色 | 深红 `#8B0000` |
| 字体 | 楷体 |
| 字号 | 小四 (12pt) |

## 字形替换规则

### 引号 → 角括号

| 原字符 | 替换为 | 位置 |
|--------|--------|------|
| " (U+201C，左双引号) | 『 (U+300E) | 上标 |
| " (U+201D，右双引号) | 』 (U+300F) | 下标 |
| ' (U+2018，左单引号) | 「 (U+300C) | 上标 |
| ' (U+2019，右单引号) | 」 (U+300D) | 下标 |
| " (全角左双引号) | 『 | 上标 |
| " (全角右双引号) | 』 | 下标 |
| ' (全角左单引号) | 「 | 上标 |
| ' (全角右单引号) | 」 | 下标 |

### 书名号 → 波浪下划线

| 原字符 | 处理方式 | 说明 |
|--------|----------|------|
| 《》 | 删除标记，对书名文字添加波浪下划线 | 符合 GB/T 15834-2011 浪线式书名号 |
| 〈〉 | 删除标记，对书名文字添加波浪下划线 | 同上 |

**实现方式：**
1. 删除 `《` `》` 字符（及其对应的 `﹏` 字符）
2. 对书名文字的 run 添加 `w:u w:val="wave" w:color="8B0000"`（深红波浪下划线）
3. 在竖排模式（`textDirection=tbRl`）下，波浪下划线**自动显示在文字左侧**

**关键：** 不能用 `﹏` (U+FE4F) 字符夹住书名（如 `﹏书名﹏`），这种方式在竖排中无法正确显示。必须用 Word 原生的波浪下划线格式。

**Run 结构处理：**
- 常见：`《` 独占 run → 直接删除 run，给下一个 run 加波浪下划线
- 双浪线 run：`﹏﹏` 合并在一个 run → 先拆分为两个独立 run 再配对处理
- 混合 run：`。﹏` 标点与浪线合并 → 先拆分 run，保留标点部分
- 书名跨 run：`《上、下经》` 中间有标点 run → 对两个标记之间的所有 run 均加波浪下划线

### 括号 → 直式括号

| 原字符 | 替换为 | 位置 |
|--------|--------|------|
| （ | ︵ (U+FE35) | 不调整 |
| ） | ︶ (U+FE36) | 不调整 |
| ( | ︵ | 不调整 |
| ) | ︶ | 不调整 |

### 角括号（原样保留）

| 字符 | 位置 |
|------|------|
| 「 『 | 上标 |
| 」 』 | 下标 |

### 其他标点

| 类型 | 位置 |
|------|------|
| ，。！？；：、…·～等 | 上标 |
| - – — (连字符/破折号) | 不调整 |

### 特殊符号

圈号数字 ①②③④⑤⑥⑦⑧⑨⑩ 等 (U+2460-U+24FF)：
- 小四(12pt)、深红、楷体
- **不调整上下标位置**

## 使用方法

1. 确认用户要处理的 .docx 文件路径
2. 运行脚本：
   ```bash
   python <skill-dir>/scripts/fix_punctuation.py <输入文件> [输出文件]
   ```
3. 默认输出：同目录加 `_标点修改` 后缀

## 自定义格式

如需不同颜色/字体/字号，参照脚本逻辑编写临时脚本，修改 `set_run_font` 参数。

常用颜色：
- 深红: `#8B0000` | 红色: `#FF0000` | 暗红: `#800000` | 朱红: `#C0322D`

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 引号未被替换 | 源码中 `"` 写成了 ASCII 直引号 (U+0022) 而非弯引号 (U+201C) | 确保 QUOTE_MAP 用 Unicode 转义：`'\u201c'`、`'\u201d'` |
| EPUB 弯引号未处理 | build 脚本的替换映射不含弯引号 | 在构建阶段也要包含 `""→『』`、`''→「」` 的映射 |

**关键提醒：** EPUB 提取的文本中引号是弯引号 `""`（U+201C/201D）和 `''`（U+2018/2019），不是 ASCII 直引号。Python 源码中直接写 `"` 会被当作直引号 (U+0022)，必须用 `\u201c`/`\u201d` 转义或从文件中复制正确的弯引号字符。
